# Encore combien de fois ?

Combien de dîners, de visites, d'étés te reste-t-il avec ceux que tu aimes ? Fais le calcul, puis change-le.

Page unique en HTML, sans dépendance ni stockage : tout se calcule dans le navigateur.
Espérances de vie : approximation des tables INSEE (France, 2024-2025). Inspiré de « The Tail End » de Tim Urban.
